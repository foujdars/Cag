# Audit Atlas landing page

A static landing page for an AI-assisted research concept that helps auditors discover relevant issues across publicly available CAG reports from Indian states.

## Run locally

From this directory, run `python3 -m http.server 8000` and open `http://localhost:8000`.

The research workspace in the hero is an illustrative preview. This repository contains the landing page only; it does not include a report index, AI search service, or live search results. Links to published reports open the [official CAG audit reports page](https://cag.gov.in/en/audit-report).
